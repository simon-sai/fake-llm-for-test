# Project rules

## Language

- Everything in this project is written in English: code, comments, identifiers, commit messages, README and other
  docs, the Worker's home page, API responses and error messages, Postman collections and test names, and sample
  request data.
- The only exception is the chat with the user, which is answered in Vietnamese.
- Files listed in `.gitignore` as local planning docs (`llm-requirements.md`, `fake-llm-plan.html`) are the user's
  own notes and are not part of the project.
